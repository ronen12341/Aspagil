# אתר אספגיל (Aspagil) - מדריך פריסה

אתר תדמית של אספגיל, מפעל הדפסת כוסות נייר מעוצבות.

## מבנה האתר

- `index.html` - דף הבית
- `about.html` - אודות + הצהרת נגישות
- `contact.html` - יצירת קשר + טופס הצעת מחיר
- `products/` - 6 דפי קטגוריות מוצרים:
  - `business-branded.html` - כוסות לעסקים
  - `disposable.html` - כוסות חד פעמיות
  - `events.html` - לאירועים וכנסים
  - `logo-print.html` - הדפסה עם לוגו
  - `food-stalls.html` - דוכני מזון ומסעדות
  - `birthdays.html` - ימי הולדת
- `assets/css/style.css` - העיצוב המשותף לכל הדפים
- `vercel.json` - הגדרות פריסה ל-Vercel

## איך להעלות את האתר ל-Vercel

### דרך 1: גרירה ושחרור (הקלה ביותר)

1. היכנסו ל-https://vercel.com והתחברו
2. לחצו על "Add New" → "Project"
3. בחרו ב-"Browse" וגררו את כל תיקיית `Gilcups` למקום המתאים
4. לחצו על "Deploy"
5. תוך דקה האתר חי באוויר עם כתובת זמנית מ-Vercel

### דרך 2: דרך GitHub (מומלץ לטווח ארוך)

1. צרו repository חדש ב-GitHub
2. העלו לתוכו את כל הקבצים בתיקייה
3. ב-Vercel לחצו "Import Project" ובחרו את הריפו
4. כל שינוי שתעלו ל-GitHub יתעדכן אוטומטית באתר

## חיבור דומיין משלכם

לאחר הפריסה, בלוח הבקרה של Vercel:
1. לכו ל-Settings → Domains
2. הוסיפו את `gilcups.com`
3. Vercel יראה לכם איך לעדכן את רשומות ה-DNS אצל מי שמנהל לכם את הדומיין

## דברים שכדאי לדעת

### הטופס

טופס הצעת המחיר כרגע **מציג רק הודעה כשמשגרים אותו** - הוא עדיין לא שולח מייל. אפשרויות:

- **Formspree** (https://formspree.io) - חיבור פשוט, חינמי לעד 50 פניות בחודש
- **Web3Forms** (https://web3forms.com) - חינמי, ללא הרשמה
- **Vercel Functions** - פתרון מובנה, דורש כתיבת קוד קצר

### הלוגו

הלוגו נטען כרגע ישירות מהאתר הקיים: `https://www.gilcups.com/wp-content/uploads/2019/06/logo.png`

לאחר הפריסה, מומלץ:
1. להוריד את הלוגו
2. לשמור אותו ב-`assets/images/logo.png`
3. לעדכן את הקישור בכל הדפים ל-`assets/images/logo.png`

### תמונות מוצר אמיתיות

כרגע בכל דף יש איור SVG כללי של כוס. כשתחליטו להוסיף תמונות אמיתיות של מוצרים:
1. שמרו אותן ב-`assets/images/`
2. החליפו את ה-SVG בקוד עם תג `<img>` רגיל

## עזרה ושינויים

אם תרצו לשנות תוכן, צבעים, להוסיף דפים או לחבר את הטופס - פשוט פנו אלי שוב והנחה אותי.
